# UC01: control measurements (2026-10-14)

Evidence for [control kit v1](../../../design/control-kit-v1.md), the UC01 block of the
[UI consolidation handoff](../../../ui-consolidation-plan.md).

## Method

- `measure-controls.mjs` (Playwright Chromium, dark scheme) visits the 13 pages from the Stats 71
  control-padding survey. The player profile is the first profile linked from `/players`. Two
  passes: desktop 1440x900, and phone 390x844 with touch, `isMobile` and DPR 2.
- On each page it records every visible `button`, link styled as a button/pill/chip, `select`,
  `summary`, `[role=button|tab|radio]` and text/search/date input. For each it stores the exact
  box, computed padding, font size/weight, radius, colours, flex gap, ARIA state, and the box and
  edge offsets of each child `svg` (for selects, the sibling chevron).
- Data: live local FastAPI/PostgreSQL through the dev servers (release
  `23be18f9-f989-4af1-9298-3742f1de82d1`), after the Stats/Players checkpoint merge (`0af99b2`).
- `controls.json` keeps every measured control except the 1,300 Stats table-cell buttons
  (`stats-cell-button`: 1,269 at 34 px and 31 at 22 px on desktop, all 40 px on phone, 4 px padding).
  `tables.py controls.json` regenerates the tables below.
- The bespoke-class inventory is a static scan: every class in `app/styles/*.css` and
  `components/*.css` whose name ends in `-button`, `-btn`, `-pill`, `-chip`, `-trigger`, `-toggle`,
  `-tab`, `-action`, `-summary` or `-item` (110 names), cross-checked against `.ts`/`.tsx` for use and
  for the element it is applied to.

Reproduce (from `dashboard/`, with the API on :8000 and the dashboard on :3100):

```bash
mkdir -p $TMPDIR/uc01 && OUT=$TMPDIR/uc01 node ../docs/evidence/ui-consolidation/uc01/measure-controls.mjs
python3 ../docs/evidence/ui-consolidation/uc01/tables.py $TMPDIR/uc01/controls.json
```

## Findings

- **Four desktop heights:** 28, 32, 36 and 40. Off-scale heights are table and row targets
  (22, 24, 26, 34-cell), the 27.5 px header nav line box, the 30 px Stats name filter, the 19.5 px
  inline "Swap A and B", and the 34 px kit bug below.
- **34 px bug:** `ui-button-md` = `min-height: 32px` + 8 px block padding + 18 px line height, so md
  buttons with text are 34 px and md icon buttons 32 px (Recent Games Profile vs Add to favorites).
  `ui-menu-trigger` (Export) and `ui-tab-trigger` (profile tabs) land on 34 the same way.
- **Padding:** 12 px is the norm at 32–40. Outliers: legacy `.button` and `button-secondary` 16;
  Stats Select Team and Draft Class 16; `ui-button-sm` 8; preset tabs 8; Stats footer 4.
- **Text:** 13 px at 32–40 (console 600, `--color-text-control`), 12 px at 28. Outliers: legacy
  `.button` 14, `button-small` 12 at 40 px, header Ask 12 at 32.
- **Icons:** 14 at 28; 16 at 32–36; mixed 14/16 at 40 (date 16; help, Data details, season
  stepper and Add View 14).
- **Gaps:** 8 px between icon and text in buttons, date and help; 4 px in nav, chips, segmented
  items and the season picker; text to chevron box 4 px in selects and the season picker, 8 px in
  `ui-menu-trigger`.
- **Phone:** every control is 40 px tall (FO14 `max-width: 767px` rule), except Similar Players'
  ten `button-secondary` actions, which wrap to two lines (60 px).
- **Chevrons:** select chevron box 9.33 px from the edge at 29.33 px end padding (instruction 71
  offset), trigger chevrons 6.2 px (3/24 offset at 14 px). No change.
