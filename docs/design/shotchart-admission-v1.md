# Event-preserving ShotChartDetail admission v1

Frozen 2026-10-03 before complete-game reconciliation or season expansion. This is an input transform/quality contract, not a change to the four B25 model protocols. Parent: [B26 handoff](../research/b26-input-readiness.md).

Source: `shufinskiy/nba_data`, revision `e829d4678be1e075f99e5d41a1c5f97089be446b`. Starting-year `shotdetail_2025` is season 2025–26. Preserve the full archive, README, field description, repository license, exact SHA-256, source URL and actual acquisition observation. Intended use is this local noncommercial research workbench. Attribute NBA Stats, the archive publisher and SportsDataverse for the independent boxes/schedule; retain Apache 2.0 and CC BY 4.0 notices with changes disclosure. Repository licensing does not settle upstream NBA rights or authorize public redistribution. Local diagnostic retention is separate from database/source admission and model fitting.

Transform: `courtload-shotchart-v1`. Normalize only explicit NBA numeric IDs: one to ten ASCII digits, left padded to ten for games; require regular-season prefix `002`, matching starting-year digits and a nonzero game suffix. Player/team/event keys are positive integers, never names or approximate clock matches. Preserve `(game_id, GAME_EVENT_ID)`, original source fields, CSV record ending line, source-member name and hashes. Names/tricodes are descriptive cross-checks, not identity substitutes.

Required target/event fields: attempted flag exactly `1`, made flag exactly `0`/`1`, matching `Made Shot`/`Missed Shot`, shot type exactly `2PT Field Goal`/`3PT Field Goal`, valid `YYYYMMDD` game date in the named season, period 1–20, integral minute/second fields with seconds <60 and clock within 720 seconds (regulation) or 300 seconds (overtime). Reject malformed/missing keys, unknown targets/types, nonfinite numbers, malformed geometry and duplicate game/event grains. Any such row quarantines its whole game. If its game identity cannot be recovered, the entire source cannot certify completeness. Sorted event IDs must have nondecreasing periods and nonincreasing remaining clocks within each period. No event is inferred, deduplicated or silently repaired.

Geometry is assessed after all-attempt reconciliation. Empty coordinate/distance fields stay null and exclude that row from model eligibility. Numeric distance must be nonnegative; negative values exclude geometry. Normalize integer legacy coordinates to feet by dividing by ten, basket at origin, positive y toward the opposite baseline. A genuine `(0,0)` and distance zero is valid. Fixed court bounds are x in [-25,25], y in [-5.25,88.75] feet. Require absolute declared-distance versus coordinate radius difference <=1.1 feet (integer distance truncation plus coordinate quantization); retain both original distance and residual. These are conservative diagnostic exclusions, not corrections. Do not fill distance from geometry or reinterpret a shot's observed 2/3 type. Zones use the existing `shot-zones-v1` classifier only on jointly eligible geometry.

Reconcile **all** source attempts, including every geometry-excluded row, against separately hashed final SportsDataverse team/player boxes and schedule bytes. Require exact game/season/phase/date and NBA side IDs, two team boxes matching final schedule scores, every player's team/side, no duplicate player/team grains, and finite nonnegative integer FGA/FGM/3PA/3PM. Counts must satisfy makes <= attempts and three-point counts <= field-goal counts. Exact four-count equality is mandatory for shots versus each team, each recorded player (including zero-attempt players), and summed player boxes versus team boxes. Missing box fields never become zero. Unexpected shooters or teams quarantine the whole game. A zero-attempt recorded player needs no shot row, but an absent positive-attempt player fails. Require points = 2*FGM + 3PM + FTM and schedule score agreement for team boxes; free throws are outside the shot estimand.

The independent regular-season denominator requires exactly 1,230 unique finalized games, 30 distinct NBA teams with 82 games each, valid dates before the audit cutoff, reciprocal distinct sides and winner/loser score agreement. Retain every expected game, extra source game, rejected row/game, reconciliation comparison and geometry exclusion. Missing games remain missing. A season with any quarantined/missing/extra game is incomplete even when its remaining attempts reconcile.

Run one explicit complete real game first. Only after that passes, scan one complete season, then the two earlier required seasons. Bounded inputs: archive <=10 MiB compressed/64 MiB expanded, one regular CSV tar member with exact expected name (no filesystem extraction), <=300,000 shot rows/season, <=1,000 attempts/game, CSV row/field limits, <=64 MiB independent source files and <=50,000 independent rows/file. Retain new offline candidate bundles by exclusive creation; never call the replacing B19 admission service or modify an existing dataset/release. Reports say `fit_authorized=false`; even a reconciled season does not clear reuse, database admission, three-season binding or the separate chronology amendment.
