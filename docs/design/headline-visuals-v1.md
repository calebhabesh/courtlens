# Headline visuals v1 (PC12 batch B)

Presentation-only views of existing CourtLens reads. No data acquisitions, publication, model fits,
metric definitions, qualification rules or sealed artifacts change. Batch C owns demo hygiene
(including Evaluation availability and public investigation titles); D owns personal example boards.

- Teams keeps its table default and adds the top five known net ratings in the current search on a
  shared zero-based scale. Game counts, source and units sit with the bars; unknown ratings are
  excluded and counted in a tile. Search does not change the table's league percentile reference.
  The optional efficiency scatter uses labeled categorical conference colors.
- Team profiles compare offense, defense and net rating to the **same-scope API league averages**.
  Every row has its own zero-based scale shared by team and league; a negative net rating retains
  its sign. Defensive rating is allowance. No overall verdict. Opponent FG%/eFG% use the already
  fetched Four Factors read when the detail response omits them; unknown stays unknown. Full team
  names wrap in the header and identity card.
- Team Compare puts paired scoring, allowance and margin bars before the entity selectors, which
  stay reachable. Amber = A, blue = B throughout its rows. Signs and exact values stay visible.
  Neither magnitude nor a shorter allowance bar produces an overall verdict.
- RAPM shows the first five qualified 1Y leaders from the existing served ordering, with portraits,
  games and minutes. It preserves API qualification, counted-control units, historical fit horizons
  and lineup-confounding disclosure. No interval is manufactured. The detail table adds portraits;
  no team is guessed when the impact response supplies no team.
- Forecasts shows observed coverage against the protocol's nominal 80%, on a fixed 0–100 scale,
  separately for core and early-season rows of baseline and challenger. Each row names forecast
  count and mean interval width. Coverage alone is not promotion evidence; gates and the full
  out-of-time tables remain. There are no fabricated forecast/actual pairs or residuals.
- Shooting plots measured **selection** reliability bins: predicted bin mean versus observed make
  rate. Empty/null bins have no point; bins are not joined. Circles/squares supplement A/B color,
  the diagonal is labeled observed = predicted, and exact bins remain in the report's table.
  This is neither final-test performance nor prospective evidence. No uncertainty interval is served.
- Trends selects a parameter-free example using the shared same-scope season-minutes rule, pins
  subject/scope in the URL, and labels Example with a Change control that opens/focuses the player
  lookup on phone as well as desktop. Explicit subjects are retained. It puts the selected player periods (A target/B baseline) on paired bars; each metric has its
  own scale, fractional percentages are converted to percent units, and numeric differences remain
  descriptive. Calendar windows are not relabeled as consecutive appearances. League Shifts has
  five signed change bars; its existing eligibility and disclosures remain.
- Player profiles put all three actual game trajectories before the long detail tables at both
  widths. Unknown observations create gaps and are excluded from means; actual zeros remain.
  Labeled metrics, endpoints, dates, known observation counts, source and dashed mean remain.
- Contracts puts cap utilization before identity/KPI tiles so the phone opens on a graphic. Payroll
  flows name the top five **known current-roster** salaries (ties by player id) and aggregate the
  others within position, with count labels. Group totals and downstream totals conserve the same
  known dollar amounts. Unknowns and players on another index roster stay outside flows, and the
  full roster/source-listed tables remain. Source totals are still lower bounds, not cap compliance.

`PairedBars` and `ReliabilityPlot` join the SVG kit and `/design` examples. They use existing v1.2
semantic tokens, typed values, the shared provenance/state frame and reduced-motion crossfades.
Phone ranked bars stack names above geometry to keep full identities readable. Headline sources,
samples and limitations precede geometry. Charts retain exact values without relying on color.
